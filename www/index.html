Worker handoff, backup and restore

Export or import one worker profile

Owner/admin: select a completed worker profile and export a shareable setup package containing that worker's details, Swipe ID and saved shifts. Worker: import the package supplied by your admin. Import adds the worker profile and keeps every profile and local self-confirmation already on this phone.

Worker packages contain the worker's details, Swipe ID and saved shifts, but never local confirmation history or PIN material. Share a package only with that worker. A duplicate worker profile is rejected without changing anything.

Full device backup

Export every worker profile, saved schedule, time-zone setting and local self-confirmation to one JSON file. The PIN hash is never included.

Backups stay on this device unless you choose a share destination.

Full restore replaces every profile and all local confirmation history on this phone. It is not the same as importing one worker profile. Export the current full backup before restoring another.
